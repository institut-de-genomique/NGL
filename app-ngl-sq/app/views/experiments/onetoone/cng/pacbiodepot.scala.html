Infos importantes sur Activation NGS-RG et nomenclature SMRT Cell si run KO

  • Dans le cas où on souhaite effectuer des analyses en local sur le séquenceur avant que le run soit pris en charge par NGS-RG :

    1. Lors de la création d'expérience, renseigner les différents champs requis et décocher Activation NGS-RG. Sauvegarder. L'expérience est à "Nouveau".
    2. Une fois les analyses en local (sur le séquenceur) terminées, revenir sur l'expérience, éditer, recocher Activation NGS-RG et renseigner le code
      SMRT Cell       (que vous trouvez dans SMRTlink > Data Management > Status > "Cell Id").Sauvegarder. L'expérience reste à "Nouveau", NE PAS DEMARRER.
    3. Les joe poursuivent la procédure habituelle (renseignent ou surchargent le code SMRT Cell, démarrent et terminent l'expérience).
    4. Les utilisateurs reviendront ensuite sur l'expérience pour orienter les containers (et cocher terminer processus). 

  • Dans le cas où on ne souhaite pas effectuer d'analyses sur le séquenceur en amont du NGS-RG :

      Laisser Activation NGS-RG coché et laisser l'expérience à "Nouveau". Poursuivre avec les points 3/ et 4/ ci-dessus.

  • Dans le cas d'un run qui plante (et pour lesquels les joe ne peuvent pas récupérer le code smrtCell) :

      Les utilisateurs doivent mettre le statut à KO + résolution adaptée, puis renseigner un faux code smrtCell = "KO" suivi de la date au format AAAAMMJJ
      suivi de la position (ligne) sur la plaque de séquençage (A ou B ou C ou D) (exemple : KO20240605B). Il doivent ensuite terminer l'expérience.
